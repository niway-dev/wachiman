## The CSS miss: `.row:focus-within { white-space: normal }` (introduced in #476)

**What the bug was.** In #476's last commit, `984e9963` ("test the skip-list guard, show full rename names to keyboard users", 2026-11-02 02:33 UTC), the rows got:

```css
.row:focus-within .rowNow, .row:focus-within .rowAfter, .row:focus-within .rowNote {
  overflow: visible; white-space: normal; overflow-wrap: anywhere;
}
```

(`reconcile.module.css:277-284` at `984e9963`). A mousedown on the 16 px checkbox focuses it, so `:focus-within` matched, the one-line names wrapped and the row grew; the box moved from under the cursor and the mouseup missed it. `git log -S"focus-within"` shows this is the only commit that adds the rule. Fixed in #484 by `de9134b3` (`:has(:focus-visible)`).
