## Signals for an AI reviewer

- Do not demand coverage numbers; Discourse has none. Ask whether the new test pins behavior at the layer that owns it.
- A changed API response under `spec/requests/api` must keep the rswag docs spec valid.
- Flag new `expects(...).never`, per-branch system specs, tests of framework behavior, and trivial-variation examples; these are written rules.
- A flaky-looking test (sleep, row order, shared cache) should be fixed, not skipped; skips need a linked reason.
- AI-co-authored patches are normal here; judge the test, not the author.
